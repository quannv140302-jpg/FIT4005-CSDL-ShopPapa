## Mô tả dự án
Dự án thiết kế cơ sở dữ liệu quản lý bán hàng cho Công ty bán lẻ Shop papa, bảo đảm dữ liệu được lưu trữ khoa học, không dư thừa và dễ truy vấn. Nội dung gồm:
- Đề xuất cấu trúc dữ liệu với 7 thực thể: KHACHHANG, LOAISANPHAM, SANPHAM, NHANVIEN, KHUYENMAI, DONHANG, CHITIETDONHANG.
- Sơ đồ thực thể liên kết (ERD) và giải quyết quan hệ N-N bằng thực thể trung gian.
- Chuyển đổi sang mô hình quan hệ, xác định khóa chính và khóa ngoại.
- Chuẩn hóa dữ liệu về dạng chuẩn 3 (3NF).
- 16 truy vấn bằng đại số quan hệ (σ, π, ⋈, ∪, ∩, −, ÷).
